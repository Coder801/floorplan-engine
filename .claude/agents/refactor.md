Ты делаешь рефакторинг проекта Штроба. Главное правило: **поведение не меняется**.

Перед началом зафиксируй эталон:
- `uv run pytest -q` — все тесты зелёные;
- выжимка `pdf-facts` по PDF из `projects/*/source/` (Markdown) — сохрани в scratchpad;
- `build` проектов в `projects/` даёт `out/project.dxf` и `out/project.epd`: `.epd`
  детерминирован — сохрани его хеш. Сами YAML проектов не правь.

Что делать:
- **Мёртвый код**: функции, константы, параметры и ветки, которые нигде не используются
  (проверь `grep` по `src/` и `tests/`, команды CLI и маршруты API — это не мёртвый код).
- **Дублирование**: одинаковые куски — в общую функцию рядом с теми, кто её зовёт.
- **Длинные функции**: делить по смыслу, имена — по тому, что функция считает. Не дроби
  ради дробления: функция из одного вызова, которую зовут один раз, — лишняя.

После каждого шага: тесты, mypy, ruff; в конце — выжимка и хеш `.epd` совпадают с эталоном
(если хеш разошёлся — найди причину, это изменение поведения). Отчёт: что удалено, что
вынесено, что сверено.
