# floorplan-engine-web — просмотр проектов

Фронт просмотра собранных проектов Shtroba: листы `.epd` в canvas, таблицы и подсказки,
правка трасс проводки, 3D проводки. React 19 + TypeScript + Vite; 3D — react-three-fiber.

Данные — API бэка (`floorplan-engine view`, порт 8000). Запросы `/api` идут к нему через прокси
Vite, поэтому CORS не нужен.

## Запуск

Одной командой из корня репозитория — `uv run floorplan-engine dev`: API и сервер разработки
вместе (при первом запуске — `npm install`), Ctrl+C останавливает оба. По отдельности:

```bash
# 1. API (из корня репозитория)
uv run floorplan-engine view                 # http://127.0.0.1:8000/api

# 2. Фронт (из web/)
npm install
npm run dev                             # http://127.0.0.1:5173 — с перезагрузкой при правках
```

API на другом адресе — переменная `API_URL`: `API_URL=http://127.0.0.1:8765 npm run dev`.

## Storybook

Компонент можно посмотреть отдельно от проекта и API: `npm run storybook`
(http://127.0.0.1:6006). История лежит рядом с компонентом —
`ИмяКомпонента/ИмяКомпонента.stories.tsx` (CSF 3, `@storybook/react-vite`), заголовок — по
группе: `Widgets/AlphaNotice`. Настройки — `.storybook/`: `main.ts` берёт `vite.config.ts`
проекта (алиас `@/`, SCSS-модули), `preview.tsx` подключает общие стили и словари, а язык
интерфейса и тему переключают кнопки панели Storybook; `preview-head.html` грузит те же шрифты,
что `index.html`. Данные компоненту история передаёт сама, сеть и API не нужны.

У каждого компонента `ui/` есть сторис: все варианты, размеры и состояния и тёмная тема. Сторис
внутри `ui/` подчиняются правилу импортов группы (`ui` → только `shared`), поэтому в них — свой
компонент и простой HTML. Что собирает несколько атомов — палитра, отступы и радиусы, шкала шрифтов
и пример вертикального ритма с сеткой 4 px, — лежит в `.storybook/foundations/` (раздел
Foundations).

## Выкладка

`dist/` — обычная статика: её отдаёт любой веб-сервер, а `/api` он проксирует на бэк.
`index.html` и `version.json` отдавайте с `Cache-Control: no-cache` (файлы `assets/` — с хешем,
их можно кэшировать надолго): по `version.json` открытая вкладка узнаёт о новой выкладке и
предлагает обновиться. Номер сборки — переменная `BUILD_ID` при `npm run build` (по умолчанию —
время сборки).
Пример nginx:

```nginx
location /api/ { proxy_pass http://127.0.0.1:8000; }
location / { root /srv/floorplan-engine-web/dist; try_files $uri /index.html; }
```

## Устройство

Код разложен по группам, импорты — от `src` через алиас `@/` (`@/shared/store`,
`@/widgets/SheetStage`); файлы своей папки — `./`.

| Папка | Что там | Можно импортировать |
| --- | --- | --- |
| `src/pages/` | экраны целиком: `Viewer` (просмотр проекта), `Welcome` (выбор проекта), `Studio` (настройки студии), `Gate` (вход) | другие `pages`, `widgets`, `ui`, `engine`, `shared` |
| `src/widgets/` | крупные блоки экрана со своим поведением и данными: области чертежа, панели, меню, карточки | `ui`, `engine`, `shared`, другие `widgets` |
| `src/ui/` | атомы интерфейса без знания о проекте: кнопки (`Button`, `IconButton`, `SegmentedControl`, `ButtonGroup`), формы (`Checkbox`, `RadioCard`, `TextField`, `TextArea`, `Select`), поверхности (`Card`, `Modal`, `Menu`, `MenuItem`, `PanelHeader`), текст (`Heading`, `Text`, `Stack`, `Tag`, `Dot`), состояния (`EmptyState`, `ErrorState`, `MarkLoader`, `Boundary`), подсказки (`HelpTip`, `Tooltip`, `HoldTip`) и чертёж (`ZoomRail`, `ScaleBar`, `EyeToggle`, `Icon`, `Logo`, `GoogleButton`); у каждого — сторис | `shared` |

| `src/shared/` | общее не-компонентное: API, состояние, типы, ключи, язык (`i18n/`), стили (`styles/`) | только `shared` |

## Имена блоков (data-ui)

Решение 2026-11-13: у каждого блока интерфейса есть имя для отладки — атрибут `data-ui` на
корневом DOM-элементе компонента. Ставит его плагин сборки `scripts/uiNames.ts` (в `dev`, сборке,
Storybook и тестах одинаково), руками писать не нужно. Имя — папка компонента (`SidePanel`),
вспомогательный компонент того же файла — `Папка.Имя` (`SidePanel.Layers`), подсказка из хука
(`useTooltip`) — по папке (`Tooltip`). В DevTools блок ищется по `[data-ui="WorkCard.Photos"]`, в
сообщении об ошибке — называется так же, а по имени сразу понятно, какой файл открыть.

Что считается корнем: JSX, который компонент возвращает (`return`, тело стрелки, обе ветки `?:`,
`&&`, `createPortal`, `render()` класса); фрагмент передаёт имя своим DOM-детям. Вложенный
компонент (`<Popover>`) извне не помечается — у него своё имя. В 3D (`@react-three/…`) — только
DOM-теги: `<mesh>` и прочее — объекты three.js. Явный `data-ui` в коде главнее — если нужно другое
имя. Компонент без имени в бандле — повод проверить, что он возвращает JSX одним из этих способов.

## Стили

SCSS-модули в папке компонента (`widgets/Drawer/index.tsx` → `Drawer.module.scss`), общие
файлы стилей подключаются через алиас (`@use "@/shared/styles/mixins" as *;`); раскладка страниц и панелей —
CSS grid (области сетки у каркаса, `grid-template-rows: auto minmax(0, 1fr)` у панелей с
прокруткой); flex — только для одного ряда кнопок или подписей.

| Файл | Что |
| --- | --- |
| `src/shared/styles/global.scss` | глобально: темы, сброс (у `button`, `input` — только сброс, вид — у компонентов `ui/`), `h1`–`h4` по шкале без внешних отступов, утилиты `mono` / `muted` / `small`, цвета `sev-*` и `st-*` (имена из данных) |
| `src/shared/styles/_tokens.scss` | отступы `--space-1…10` (сетка 4 px), радиусы `--radius-sm…xl`, высоты `--control-h` (36) и `--control-h-lg` (44), тень диалога; цвета — CSS-переменные (тема переключается без пересборки, их же читает `palette.ts`); тёмная — палитра «Dark 2026» из VS Code (`2026-dark.json`: фон #121314, панели #191A1B, виджеты #202122, рамки #2A2B2C, акцент #297AA0); в 3D тёмные цвета стен и рёбер — в `widgets/Scene3D` |
| `src/shared/styles/_mixins.scss` | переломы `$narrow` / `$phone`, шрифты, шкала шрифтов `$type` и миксин `type(роль)`, миксины `button-base` (вид кнопки для `ui/`, которым нельзя импортировать `Button`), `focus-ring`, `raised`, `bare-button`, `pairs`, `no-motion` |
| `src/shared/styles/ui.module.scss` | общие части раскладки: опции чертежа справа сверху (`options`, CSS grid): постоянный ряд `optionsRow` с «Загрузить» и второй ряд `strip` с тем, что открывают 3D и «Править», подсказка и линейка под чертежом (`toolbar`), тело панели с подписями разделов (`panelBody`) |
| `src/shared/styles/menu.module.scss` | вид выпадающего меню: его берут `ui/Menu`, `ui/MenuItem` и `ui/Select` |
| `src/shared/cx.ts` | склейка классов: `cx(css.card, done && css.done)` |

Типографика и ритм (решение 2026-11-13). Каждый текст — одна из ролей шкалы `$type`
(`_mixins.scss`): `display` 32/40, `title` 22/28 (h1), `heading` 16/24 (h2), `subheading` 14/20
(h3), `body` 14/20, `small` 12/16, `caps` 11/16 (h4, подписи разделов). Высота строки всегда кратна
4 px, как и отступы `--space-*`, поэтому блоки стоят на одной сетке. В разметке — компоненты
`Heading` (уровень `level` отдельно от вида `size`) и `Text`, в модуле для тега, который компонентом
не обернуть (ячейка таблицы, подпись SVG), — `@include type(роль)`. Размер шрифта и высоту строки
числами в модулях не пишите. Отступ между блоками задаёт контейнер (`gap` сетки или `Stack`), а не
`margin` заголовка или абзаца: у `h1`–`h6` и `p` внешних отступов нет. Исключение — поток в
`panelBody`: там подпись раздела сама держит отступ сверху.

Кнопки, поля, чекбоксы, карточки, диалоги — только компоненты `ui/`. Глобальный стиль `button`
сброшен; своя кнопка виджета (вкладка, плитка, строка списка) задаёт себе вид в модуле и подключает
`focus-ring`. Класс компонента перебивается классом виджета, если правило виджета сильнее или стоит
позже: CSS модуля компонента попадает в сборку раньше модуля виджета, который его импортирует.

Имена классов в коде — camelCase (`.row-btns` → `css.rowBtns`, Vite `localsConvention:
"camelCaseOnly"`; цифра перед буквой тоже меняет регистр: `.layer3d` → `layer3D`). Типы модулей —
`*.module.scss.d.ts` рядом с файлом: их пишет `scripts/css-types.mjs` (имена считает сам Vite)
перед `check`, `build` и `dev`, а в разработке — при каждой правке `.scss`; в git их нет.
Опечатка в `css.имя` — ошибка `tsc`. Чужие классы (SVG превью из `epd/thumbnail.py`, `.drag` у
холста из `SheetView`) — через `:global(...)` внутри своего класса.

Узкий экран (`$narrow`, 900px): чертёж на всю высоту, боковая панель — нижней шторкой (полоса
с видом и «▴»), второй ряд опций чертежа — полосой с прокруткой, выдвижная панель — на весь
экран. Телефон (`$phone`, 560px): действия шапки — в меню «⋯», листы — полосой с прокруткой.
Масштаб на касание — щипок двумя пальцами (`engine/sheet/pinch.ts`, лист, щит и развёртка).
