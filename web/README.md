# floorplan-engine-web — просмотр проектов

Фронт просмотра собранных проектов Штроба: листы `.epd` в canvas, таблицы и подсказки,
правка трасс проводки, 3D проводки. React 18 + TypeScript + Vite; 3D — react-three-fiber.

Данные — API бэка (`floorplan-engine view`, порт 8000). Запросы `/api` идут к нему через прокси
Vite, поэтому CORS не нужен.

## Запуск

Одной командой из корня репозитория — `uv run floorplan-engine dev`: API и сервер разработки
вместе (при первом запуске — `npm install`), Ctrl+C останавливает оба. По отдельности:

```bash
# 1. API (из корня репозитория)
uv run floorplan-engine view                 # http://127.0.0.1:8000/api

# 2. Фронт (из web/)
npm install
npm run dev                             # http://127.0.0.1:5173 — с перезагрузкой при правках
```

API на другом адресе — переменная `API_URL`: `API_URL=http://127.0.0.1:8765 npm run dev`.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | сервер разработки, порт 5173 |
| `npm run build` | проверка типов и сборка в `dist/` |
| `npm run preview` | собранный `dist/` на порту 4173 (с тем же прокси к API) |
| `npm run check` | типы SCSS-модулей и TypeScript |
| `npm test` | тесты (vitest) |

## Выкладка

`dist/` — обычная статика: её отдаёт любой веб-сервер, а `/api` он проксирует на бэк.
`index.html` и `version.json` отдавайте с `Cache-Control: no-cache` (файлы `assets/` — с хешем,
их можно кэшировать надолго): по `version.json` открытая вкладка узнаёт о новой выкладке и
предлагает обновиться. Номер сборки — переменная `BUILD_ID` при `npm run build` (по умолчанию —
время сборки).
Пример nginx:

```nginx
location /api/ { proxy_pass http://127.0.0.1:8000; }
location / { root /srv/floorplan-engine-web/dist; try_files $uri /index.html; }
```

| `src/tabs.ts` | вкладки: продолжения развёрток — страницы «‹ 1 / 3 ›»; электрика, освещение, проводка — вкладка «Электрика» с видами «Точки · Освещение · Проводка» справа (печатные листы — отдельные) |
| `src/SheetStage.tsx` | область чертежа: лист или 3D, кнопки под ним |
| `src/SidePanel.tsx` | боковая панель: таблицы, слои, вопросы, исходники, проект |
| `src/Tip.tsx`, `src/SourceView.tsx` | подсказка объекта (закреплённая — ×, Esc, смена листа); исходник на месте листа |
| `src/version.ts`, `src/Boundary.tsx` | проверка выкладки (номер сборки в бандле против `/version.json`, версия формата `.epd`); ошибка листа — сообщением, а не пустым холстом |
| `src/sheet/SheetView.ts` | рисование чертежа в canvas (вне React), масштаб, выделение; вкладка того же чертежа — `setPage`, без нового холста |
| `src/sheet/drawing.ts` | один чертёж на листы с планом (план, электрика, освещение, проводка): листы совмещены по `model`, слой — с первого листа, где он есть; вкладка — набор своих слоёв, чужие включаются в «Слоях» |
| `src/edit/` | правка трасс; `geometry.ts` — чистые функции с тестами |
| `src/three/Scene3D.tsx` | 3D чертежа на любой его вкладке (сцена листа проводки): видно то, что в слоях вкладки — план без точек, освещение без розеток; отдельный файл, грузится по кнопке «3D» |
| `src/Filter3D.tsx` | фильтр 3D: помещение и группы QF (флажки, «только») |
| `src/store.ts` | общее состояние: под курсором, выделение, слои, режимы |
| `src/types.ts` | типы API и формата `.epd` — держать в согласии с `docs/epd-format.md` |

## Стили

SCSS-модули рядом с компонентами (`App.tsx` → `App.module.scss`), раскладка страниц и панелей —
CSS grid (области сетки у каркаса, `grid-template-rows: auto minmax(0, 1fr)` у панелей с
прокруткой); flex — только для одного ряда кнопок или подписей.

| Файл | Что |
| --- | --- |
| `src/styles/global.scss` | глобально: темы, сброс, теги, утилиты `mono` / `muted` / `small`, цвета `sev-*` и `st-*` (имена из данных) |
| `src/styles/_tokens.scss` | цвета — CSS-переменные (тема переключается без пересборки, их же читает `palette.ts`) |
| `src/styles/_mixins.scss` | переломы `$narrow` / `$phone`, шрифты, миксины `raised`, `bare-button`, `pairs`, `no-motion` |
| `src/styles/ui.module.scss` | общие части: кнопки под чертежом (`toolbar`, `group`), сегменты, заголовок и тело панели, пусто / ошибка |
| `src/cx.ts` | склейка классов: `cx(css.card, done && css.done)` |

Имена классов в коде — camelCase (`.row-btns` → `css.rowBtns`, Vite `localsConvention:
"camelCaseOnly"`; цифра перед буквой тоже меняет регистр: `.layer3d` → `layer3D`). Типы модулей —
`*.module.scss.d.ts` рядом с файлом: их пишет `scripts/css-types.mjs` (имена считает сам Vite)
перед `check`, `build` и `dev`, а в разработке — при каждой правке `.scss`; в git их нет.
Опечатка в `css.имя` — ошибка `tsc`. Чужие классы (SVG превью из `thumbnail.py`, `.drag` у
холста из `SheetView`) — через `:global(...)` внутри своего класса.

Узкий экран (`$narrow`, 900px): чертёж на всю высоту, боковая панель — нижней шторкой (полоса
с видом и «▴»), кнопки под чертежом — одной полосой с прокруткой, выдвижная панель — на весь
экран. Телефон (`$phone`, 560px): действия шапки — в меню «⋯», листы — полосой с прокруткой.
Масштаб на касание — щипок двумя пальцами (`sheet/pinch.ts`, лист и щит).
