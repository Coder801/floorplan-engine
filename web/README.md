# floorplan-engine-web — просмотр проектов

Фронт просмотра собранных проектов Штроба: листы `.epd` в canvas, таблицы и подсказки,
правка трасс проводки, 3D проводки. React 18 + TypeScript + Vite; 3D — react-three-fiber.

Данные — API бэка (`floorplan-engine view`, порт 8000). Запросы `/api` идут к нему через прокси
Vite, поэтому CORS не нужен.

## Запуск

Одной командой из корня репозитория — `uv run floorplan-engine dev`: API и сервер разработки
вместе (при первом запуске — `npm install`), Ctrl+C останавливает оба. По отдельности:

```bash
# 1. API (из корня репозитория)
uv run floorplan-engine view                 # http://127.0.0.1:8000/api

# 2. Фронт (из web/)
npm install
npm run dev                             # http://127.0.0.1:5173 — с перезагрузкой при правках
```

API на другом адресе — переменная `API_URL`: `API_URL=http://127.0.0.1:8765 npm run dev`.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | сервер разработки, порт 5173 |
| `npm run build` | проверка типов и сборка в `dist/` |
| `npm run preview` | собранный `dist/` на порту 4173 (с тем же прокси к API) |
| `npm run check` | типы SCSS-модулей и TypeScript |
| `npm test` | тесты (vitest) |

## Выкладка

`dist/` — обычная статика: её отдаёт любой веб-сервер, а `/api` он проксирует на бэк.
`index.html` и `version.json` отдавайте с `Cache-Control: no-cache` (файлы `assets/` — с хешем,
их можно кэшировать надолго): по `version.json` открытая вкладка узнаёт о новой выкладке и
предлагает обновиться. Номер сборки — переменная `BUILD_ID` при `npm run build` (по умолчанию —
время сборки).
Пример nginx:

```nginx
location /api/ { proxy_pass http://127.0.0.1:8000; }
location / { root /srv/floorplan-engine-web/dist; try_files $uri /index.html; }
```

## Устройство

Код разложен по группам, импорты — от `src` через алиас `@/` (`@/shared/store`,
`@/widgets/SheetStage`); файлы своей папки — `./`.

| Папка | Что там | Можно импортировать |
| --- | --- | --- |
| `src/pages/` | экраны целиком: `Viewer` (просмотр проекта), `Welcome` (выбор проекта), `Gate` (вход) | другие `pages`, `widgets`, `ui`, `engine`, `shared` |
| `src/widgets/` | крупные блоки экрана со своим поведением и данными: области чертежа, панели, меню, карточки | `ui`, `engine`, `shared`, другие `widgets` |
| `src/ui/` | мелкие переиспользуемые компоненты без знания о проекте: `Logo`, `Boundary`, `ZoomRail`, `ScaleBar` | `shared` |
| `src/engine/` | холсты вне React (классы и чистые функции): лист, щит, развёртка, правка трасс, геометрия 3D | `shared`, другие `engine` |
| `src/shared/` | общее не-компонентное: API, состояние, типы, ключи, язык (`i18n/`), стили (`styles/`) | только `shared` |

Компонент — папка `ИмяКомпонента/`: точка входа `index.tsx` (сам компонент и его типы),
стили — `ИмяКомпонента.module.scss`, тесты и вспомогательные файлы — рядом в той же папке.
Один компонент — одна папка; второй экспортируемый компонент — своя папка. Раскладку и правило
импортов проверяет `src/structure.test.ts`.

| Путь | Что |
| --- | --- |
| `pages/Viewer` | проект из адреса (`#имя`), листы, шапка, выбор области чертежа по листу |
| `pages/Welcome` | экран приветствия: карточки проектов на всю страницу |
| `pages/Gate` | вход (`shared/auth.ts`): карточка по центру — знак, «Вход», кнопка Google, «или», код на почту (`widgets/EmailLogin`); выбор «кто вы» («Мой ремонт» или «Фирма») — в такой же карточке, «Фирма» — регистрация формой `widgets/FirmForm` (название, вид, город, телефон); приглашение; вход выключен — страница открыта |
| `widgets/SheetStage` | область чертежа: лист (`engine/sheet/SheetView`) или 3D, кнопки под ним, правка трасс |
| `widgets/PanelStage`, `widgets/DeviceCard` | щит в лицо в своём canvas (`engine/panel/`), карточка аппарата по клику |
| `widgets/ElevationStage` | развёртка в своём canvas из ключа `elevations` страницы (`engine/elevation/ElevationView`; раскладка подписей — `layout.ts` с тестами): без слоёв и подсветки общего чертежа; номера точек — плашками цвета группы; место под мини-схему — слева или снизу, где стена крупнее; кнопка «Изометрия» — стена под 45° с частью соседней в углу 90° (оба угла 90° — левый; `engine/elevation/iso.ts` с тестами: камера, матрицы плоскостей стен, контур с обрывом): тот же плоский рисунок стены через матрицу её плоскости (`flatToIso`; попадания курсора — через обратную), поэтому номера, пунктиры к шкалам и подписи размеров — тоже изометрические; высоты — у дальнего от угла края; сосед полупрозрачный, без шкал, где он идёт дальше — край волной; линейки нет; под курсором и закреплённое — поверх остального (в обоих видах); выбор вида запоминается в браузере |
| `widgets/WallItems` | боковая панель развёртки «На стене»: номер, что, отступ × высота, группа и откуда линия; строка ↔ объект на стене; «На проводке →» — лист проводки сразу с этой линией (`store.goto`, `SheetView.reveal`) |
| `widgets/WallPager`, `widgets/WallMap` | пейджер развёрток «‹ имя стены · 5 / 32 ▾ ›» со списком всех стен; мини-схема квартиры в изометрии со стеной цветом и жёлтым человечком перед ней, как на картах, взгляд — клином на полу (`engine/sheet/wallMap.ts`, грань стены — `face` развёртки) |
| `widgets/SidePanel` | боковая панель листа: виды «Электрики», таблицы, слои; у развёрток — «На стене» |
| `widgets/Drawer` | выдвижная панель шапки: вопросы, исходники, проект |
| `widgets/ProjectsMenu`, `widgets/ProjectCard` | меню проектов слева; карточка проекта (превью плана, этапы) — и в меню, и на `Welcome`; помещения на превью — цветом по виду (классы `wet`, `kitchen`, `outdoor`, `service`, `living` из `thumbnail.room_kind`, оттенок смешан с фоном карточки — одни правила для обеих тем) |
| `widgets/Settings` | шестерёнка в шапке: аккаунт и «Выйти», план (тип учётки), тема, язык интерфейса |
| `widgets/DownloadMenu` | «Скачать» в правом верхнем углу чертежа: PNG листа для альбома или DXF проекта |
| `widgets/EstimateStage` | вкладка «Смета» (после листов): смета электрики во всю ширину из ключа `estimate` страницы проводки — разделы, позиции (без цены — приглушённо), итоги; «Скачать Excel» — `out/estimate.xlsx`; итоги и примечания — в боковой панели (`shared/estimate.ts`: вид строки, итоги) |
| `widgets/Tip`, `widgets/SourceView` | подсказка объекта (закреплённая — ×, Esc, смена листа); исходник на месте листа |
| `widgets/Scene3D`, `widgets/Filter3D` | 3D чертежа (react-three-fiber; отдельный чанк, грузится по кнопке «3D»): видно то, что в слоях вкладки; фильтр 3D по помещению и группам QF |
| `ui/ZoomRail`, `ui/ScaleBar` | масштаб всех холстов (`shared/zoom.ts`) — пять шагов от «вписано»: 100, 150, 200, 300, 400 %; вертикальная шкала справа по центру чертежа («+», позиции шагов — клик или ползунок, «−», «вписать»), колесо и щипок — на соседний шаг; переход плавный (`Glide`, точка под курсором стоит на месте), между шагами и за ними масштаба нет (3D — без шагов); линейка внизу справа в мм модели, щита или стены |
| `ui/Boundary`, `ui/Logo` | ошибка листа — сообщением, а не пустым холстом; знак Штробы |
| `ui/HelpTip` | значок «?» или «i» (`mark`, `size`, `align`) с подсказкой: наведение, фокус, клик (на телефоне — касание); закрывается кликом мимо и Esc; на входе — «почему без паролей», в смете — что входит в позицию (`hint` строки) |
| `ui/GoogleButton` | «Продолжить с Google» по правилам Google: цветной знак «G», белая с серой рамкой, в тёмной теме — тёмная |
| `engine/sheet/` | `SheetView.ts` — чертёж в canvas, масштаб, выделение (вкладка того же чертежа — `setPage`); `drawing.ts` — один чертёж на листы с планом (листы совмещены по `model`, вкладка — набор своих слоёв, чужие — в «Слоях»); `walls.ts` — развёртки по одной; `paint.ts`, `pinch.ts` (щипок) |
| `engine/panel/` | щит в лицо: `layout.ts` — раскладка по рейкам (тесты), `catalog.ts` — отрисовщики аппаратов, `PanelView.ts` (нутро корпуса — светлое в любой теме: заливка, гребёнки и подложка проводов внутри — не через `screenColor`) |
| `engine/elevation/`, `engine/edit/`, `engine/three/` | развёртка в canvas; правка трасс (`geometry.ts` — чистые функции с тестами); рёбра стен для 3D |
| `shared/i18n/` | язык интерфейса — i18next + react-i18next: `ru.ts` (источник ключей), `uk.ts`, `en.ts` той же формы (тип `Messages`: нет ключа — ошибка типов; `i18n.test.ts` сверяет подстановки `{{…}}`), `index.ts` — запуск, `setLanguage`, `label(группа, ключ)` для значений из данных. Язык — выбор в настройках (запоминается), иначе язык браузера, иначе русский. Компоненты берут `t` из `useTranslation`, код вне React — `i18n.t`. Чертежи, таблицы, карточки и вопросы — на языке проекта (`room.yaml: language`); интерфейс их не переводит. Новая строка интерфейса — ключ во все три словаря |
| `shared/store.ts` | общее состояние: под курсором, выделение, слои, режимы, переход на объект (`goto`) |
| `shared/types.ts` | типы API и формата `.epd` — держать в согласии с `docs/epd-format.md` |
| `shared/tabs.ts` | вкладки: продолжения развёрток — одна вкладка; электрика, освещение, проводка — вкладка «Электрика» с видами справа (печатные листы — отдельные); подпись — по теме листа на языке интерфейса |
| `shared/version.ts` | проверка выкладки: номер сборки в бандле против `/version.json`, версия формата `.epd` |
| `shared/rebuild.ts` | проект пересобрали, пока вкладка открыта (`build` в терминале): время сборки `built` раз в 10 с и при возврате на вкладку — изменилось, листы перечитываются, открытая стена развёртки остаётся |
| `shared/api.ts`, `auth.ts`, `page.ts`, `popover.ts`, `palette.ts`, `files.ts`, `consts.ts` | запросы к API, вход, связи объектов страницы, всплывающее меню, цвета темы, вид файла исходника, ключи и параметры показа |

## Стили

SCSS-модули в папке компонента (`widgets/Drawer/index.tsx` → `Drawer.module.scss`), общие
файлы стилей подключаются через алиас (`@use "@/shared/styles/mixins" as *;`); раскладка страниц и панелей —
CSS grid (области сетки у каркаса, `grid-template-rows: auto minmax(0, 1fr)` у панелей с
прокруткой); flex — только для одного ряда кнопок или подписей.

| Файл | Что |
| --- | --- |
| `src/shared/styles/global.scss` | глобально: темы, сброс, теги, утилиты `mono` / `muted` / `small`, цвета `sev-*` и `st-*` (имена из данных) |
| `src/shared/styles/_tokens.scss` | цвета — CSS-переменные (тема переключается без пересборки, их же читает `palette.ts`); тёмная — палитра «Dark 2026» из VS Code (`2026-dark.json`: фон #121314, панели #191A1B, виджеты #202122, рамки #2A2B2C, акцент #297AA0); в 3D тёмные цвета стен и рёбер — в `widgets/Scene3D` |
| `src/shared/styles/_mixins.scss` | переломы `$narrow` / `$phone`, шрифты, миксины `raised`, `bare-button`, `pairs`, `no-motion` |
| `src/shared/styles/ui.module.scss` | общие части: кнопки под чертежом (`toolbar`, `group`), сегменты, заголовок и тело панели, пусто / ошибка |
| `src/shared/cx.ts` | склейка классов: `cx(css.card, done && css.done)` |

Имена классов в коде — camelCase (`.row-btns` → `css.rowBtns`, Vite `localsConvention:
"camelCaseOnly"`; цифра перед буквой тоже меняет регистр: `.layer3d` → `layer3D`). Типы модулей —
`*.module.scss.d.ts` рядом с файлом: их пишет `scripts/css-types.mjs` (имена считает сам Vite)
перед `check`, `build` и `dev`, а в разработке — при каждой правке `.scss`; в git их нет.
Опечатка в `css.имя` — ошибка `tsc`. Чужие классы (SVG превью из `epd/thumbnail.py`, `.drag` у
холста из `SheetView`) — через `:global(...)` внутри своего класса.

Узкий экран (`$narrow`, 900px): чертёж на всю высоту, боковая панель — нижней шторкой (полоса
с видом и «▴»), кнопки под чертежом — одной полосой с прокруткой, выдвижная панель — на весь
экран. Телефон (`$phone`, 560px): действия шапки — в меню «⋯», листы — полосой с прокруткой.
Масштаб на касание — щипок двумя пальцами (`engine/sheet/pinch.ts`, лист, щит и развёртка).
