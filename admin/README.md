# Shtroba admin

Админка платформы для владельца (суперпользователя): студии, люди, проекты, участники,
приглашения, коды доступа, доступ поддержки, журнал. Решение 2026-11-03 — `docs/database.md`,
«Админка платформы». Отдельный проект, как `web/`: React 18 + TypeScript + Vite, своя сборка.

```bash
npm install
npm run dev      # http://127.0.0.1:5174/admin/ ; API — floorplan-engine view (8000), другой адрес: API_URL=… npm run dev
npm run check    # типы
npm test         # vitest
npm run build    # dist/ с base /admin/
```

Вход — в просмотре (`web/`): cookie сессии общая, потому что админка живёт на том же домене по
пути `/admin/` (на сервере её отдаёт Caddy, `deploy/Caddyfile`; локально cookie на 127.0.0.1
общая для всех портов). Не вошли или не суперпользователь — экран с объяснением; API
`/api/admin/*` и так отвечает 401 или 403.

## Устройство

Вариант B макета: разделы | список | карточка; сводка и журнал — на всю ширину. У каждой
записи свой адрес в hash (`#/projects/<id>`, `#/events?project=<id>`), ссылки на человека,
студию и проект переключают раздел.

| Где | Что |
| --- | --- |
| `src/App.tsx` | проверка входа и раскладка |
| `src/pages/` | разделы: `Summary`, `Studios`, `Users`, `Projects`, `Events` (список и карточка) |
| `src/components/ui.tsx` | статус с точкой, подтверждение на месте, диалог, загрузка (`useLoad`), действие с ошибкой 409 рядом (`useAction`) |
| `src/components/dialogs.tsx` | выбор человека из базы с ролью, одноразовый код или ссылка, выдача кода и приглашения |
| `src/shared/api.ts`, `types.ts` | запросы `/api/admin/*` и ответы — в согласии с `service/db/admin.py` |
| `src/shared/route.ts` | адрес экрана в hash |
| `src/shared/text.ts`, `format.ts` | надписи (пока русские) и даты |
| `src/shared/global.scss`, `components/ui.module.scss` | темы — как у просмотра (держать в согласии с `web/src/shared/styles/_tokens.scss`), общие стили |

Нарушение правила доступа (одно пространство, один проект у клиента, у студии остаётся
владелец) API возвращает 409 с причиной — она показывается рядом с действием. Код доступа и
ссылка-приглашение показываются один раз: API их больше не отдаёт.
