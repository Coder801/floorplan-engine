# Эталон: 381922.207.1992-МЗ1 (РД)

Разобран через ODA File Converter → DXF → ezdxf, 2026-10-20.

Это рабочая документация (РД) по сетям связи (МЗ1) для защитного сооружения на 1200 мест при АЭС, выполненная в конструкторском бюро. Электрики квартир здесь нет, но состав комплекта, листы, таблицы и поля — образец профессионального оформления по ДСТУ.

## Состав комплекта

Под каждую систему в комплекте пара листов:
- **«Схема структурна … Список абонентів / Таблиця кабельних з'єднань»** — рисуется прямо на листе (paperspace), без видового экрана;
- **«План розташування …»** — подложка плана через 1–2 видовых экрана, масштабы 1:100 и 1:150.

Плюс общие листы:
- Арк1 «Загальні дані»: примечания, ведомость листов, «Документи, які додаються»;
- принципиальная схема шкафа и фасад шкафа;
- план трассы и схема прокладки внешних сетей;
- «Кабельний журнал» (20.1–20.8);
- отдельный лист `С` — **Специфікація обладнання, виробів та матеріалів**.

**Смета — отдельный документ**, а не таблица на чертеже. В «Документи, які додаються» перечислены:
- `….С` — Специфікація;
- `….ЛК1–ЛК3` — Локальний кошторис.

На чертеже — спецификация с количествами, а цены — в кошторисе.

## Поля (FIELD, 1438 шт.)

- 638 полей площади `\AcObjProp.16.2 Object(…).Area \f "%lu2%pr1%ds44%ct8[1.000000000000000E-006]"`: м² с запятой, 1 знак после запятой. Цель — замкнутая LWPOLYLINE на отдельном слое `214_w_площа`. Носители — ячейки «Експлікації» и подписи помещений вида `Протипожежна секція 1/1\PПлоща - %<…>%м²`.
- **У 396 из 638 полей площади цель удалена.** Такое поле в AutoCAD показывает `####`. Живое поле ломается, если удалить или пересоздать контур. Пользователей надо предупреждать, а наш генератор должен рисовать контур помещения отдельным объектом, который никто не трогает.
- Ещё встречаются: `Length` / `ArcLength` (длины трасс), `AcVar Filename`, параметры динамических блоков (`Parameter(n).lookupString`) в рамках, `AcExpr`.
- Структура полей совпадает с [fields.py](../src/shtroba/fields.py): контейнер `_text` с состоянием 13 и `ACFD_FIELDTEXT_CHECKSUM`. Контрольная сумма сверена на двух примерах. У дочернего поля 91 = 0 и `ACAD_ROUNDTRIP_2008_FIELD_EVALOPTION` = 63, кэш хранится числом (мм²).

## Листы и штамп

- Листы `Арк1…Арк16`, `С`. Формат задаётся **динамическим блоком рамки** с атрибутом `ФОРМАТ` (А4х3, А3х5, А1…), а не настройками печати: у всех листов `paper_size` равен 210 × 297.
- Штамп — блок с атрибутами. Форма для чертежей (`*_Г1`): РОЗРОБИВ, ПЕРЕВІРИВ, НАЧ_ВІДД, Н_КОНТР, ГІП, ПОЗНАЧ_ДОКУМ, ОБ'ЄКТ… Форма для текстовых документов (`*_ф3`): Загальні дані, Специфікація.
- Видимость слоёв по видовым экранам **не используется** (frozen = 0): разные планы — разные области модели.
- На каждом плане есть «Умовні позначення» и примечание «* Відмітки уточнити за місцем».
- На трассах подписаны длины (`-48,0-`), у оборудования — маркировка-идентификатор (`MQ22K001`): буквенный код системы, номер и номер кабеля.
